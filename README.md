# ☕ Curso de Java

> Un camino basico para aprender Java desde cero, paso por paso :D

## Ruta del curso

| Modulo | Tema | Meta |
|---|---|---|
| 01 | Esqueleto | Entender una clase y `main` |
| 02 | Variables y calculos | Guardar datos y operar con ellos |
| 03 | Decisiones | Usar `if`, `else` y `switch` |
| 04 | Ciclos | Repetir tareas con `for` y `while` |
| 05 | Metodos | Reutilizar codigo |
| 06 | Arrays | Trabajar con varias posiciones |
| 07 | POO basica | Crear objetos y clases |
| 08 | Proyecto final | Un mini gestor de notas |

## Como usarlo

1. Abre un modulo.
2. Lee su README.
3. Ejecuta el archivo `Main.java`.
4. Cambia valores y prueba que pasa. Equivocarse tambien enseña :)

Cada modulo es independiente para que puedas practicar sin perderte.
